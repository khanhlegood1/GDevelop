## 1. Phạm vi lát cắt

1. **Python lock có hash** — `apps/gon-adk/requirements.lock` (toàn bộ
   transitives + sha256, sinh bởi `pip-compile --generate-hashes`); CI cài
   `pip install --require-hashes -r requirements.lock` + `pip install -e .
   --no-deps` — không còn "pip install -e .[dev]" bay không ràng buộc.
2. **SBOM CycloneDX 1.5** — `apps/gon-adk/sbom.cdx.json` (74 components, sinh
   từ lock) + `apps/gon-web/sbom.cdx.json` (262 components, `npm sbom` built-in
   — không thêm dependency). Kèm `scripts/supply-chain/generate-sbom.sh` tái
   tạo lock + SBOM bằng tooling ghim (`pip-tools==7.6.2`, `cyclonedx-bom==5.1.0`).
3. **Đóng `CVE-2026-114603` có quản trị** (xem §2): nâng `google-adk`
   2.12.0→**2.13.0** (otel cap ≤1.42.1→**≤1.44**, otel family lên **1.44.0**),
   hạ `lxml` PYSEC-2026-87 khỏi graph (lxml chỉ vào qua extras — graph deploy
   không còn nó), và thay `pip_audit --ignore-vuln` trần trong CI bằng cổng
   **exception có quản trị** `check-exceptions.py` + `security-exceptions.toml`.
4. **Coverage gate** — `@vitest/coverage-v8@5.0.5` + `npm run test:coverage`
   + floor chống hồi quy trong `vitest.config.mts` + step CI.
5. **npm audit pin** — `npm ci` + `package-lock.json` là nguồn sự thật (đã có);
   CI giữ `npm audit --audit-level=high`; bổ sung npm SBOM cho truy vết.
