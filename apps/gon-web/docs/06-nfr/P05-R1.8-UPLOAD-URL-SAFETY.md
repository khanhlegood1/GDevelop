## 1. Yêu cầu (P03 `IDENTITY-AUTHORIZATION-PRIVACY-AND-RETENTION.md` §8)

- Không thực thi file upload; kiểm tra magic bytes/MIME, size và malware scan
  theo loại; archive/executable bị từ chối trong Alpha.
- URL fetch chống SSRF/DNS rebinding; không theo redirect vào private network.
- Không vượt paywall/login hoặc điều khoản nền tảng để lấy nội dung.

Nền đã có từ R1.4/VS1 (giữ nguyên): `assertPublicHttpUrl` chặn URL credential,
localhost/.local/.internal, IP private/reserved dạng literal; MIME allowlist
(PNG/JPEG/WebP; PDF/TXT/MD/CSV/JSON), chối archive/executable ở declaration,
size cap 25 MB/15 MB; `detectFile` magic-byte sniffing + block khi MIME lệch
khai báo. **Khoảng trống của slice này**: malware-scan hook tập trung, và
"future fetcher" chống SSRF mà comment trong `artifacts.ts` yêu cầu.

## 2. Đã triển khai

### 2.1 Content-safety scanner (`src/server/content-safety.ts`)

- `ContentSafetyScanner` port + `LocalContentSafetyScanner` deterministic,
  fail-closed, **không bao giờ thực thi bytes**:
  - chữ ký executable/archive: PE `MZ`, ELF, Mach-O, ZIP/JAR, RAR, 7z, WASM,
    shebang `#!` → `SAFETY_*` blocked **bất kể declared MIME**;
  - chuỗi EICAR chuẩn antivirus test (trong bytes hoặc text) →
    `SAFETY_MALWARE_SIGNATURE`;
  - `needs_review` dành cho tích hợp malware-scanner từ xa sau này.
- Nối vào cả 3 đường xử lý (`processTextArtifact`, `processUploadedObject`,
  `processUrlArtifact`) qua helper `blockArtifact` dùng chung: fail-closed →
  `safetyStatus/extractionStatus = blocked`, `failureCode` là reason code, emit
  `artifact.blocked` (đúng machine P03).

### 2.2 SSRF-safe URL fetcher (`src/server/url-fetcher.ts`)

- `SafeUrlFetcher.fetchContent(url)`: **mỗi hop** của chuỗi redirect được
  validate lại từ đầu:
  1. `assertPublicHttpUrl` (scheme, credential, hostname nội bộ, IP literal);
  2. **DNS resolution check** — mọi địa chỉ phân giải được phải public
     (chống DNS rebinding ở thời điểm phân giải);
  3. redirect theo `redirect: "manual"`, cap số hop (5), chặn vòng lặp;
  4. **không gửi cookie/credentials** (`credentials: "omit"`); 401/402/403 →
     `URL_ACCESS_RESTRICTED` — **không** vượt login/paywall (P03);
  5. body cap 5 MB, timeout 10 s, content-type allowlist
     (html/txt/pdf/json/markdown).
- Nối vào `processUrlArtifact` **tùy chọn** qua option `urlFetcher`:
  - không cấu hình (mặc định VS1): URL artifact vẫn metadata-only, **không** có
    fetch bên thứ ba;
  - có cấu hình: fetch → scan content → extract text như text artifact;
    blocked/restricted → fail-closed; lỗi transport → fallback metadata-only
    (link artifact vẫn dùng làm bằng chứng).
- Giới hạn ghi nhận trung thực (khắc phục khi có staging): ghim TCP connection
  vào IP đã validate (custom agent) chưa làm được với fetch API chuẩn; production
  phải chạy từ egress cô lập không có route tới private network.

Điểm chứng minh chính (`tests/production/url-safety.test.ts`):

1. **Scanner:** MZ/ELF/ZIP/shebang/EICAR bị block đúng reason code; text học
   tập bình thường được allow.
2. **Wiring fail-closed:** text artifact chứa EICAR → `blocked` +
   `artifact.blocked` event (dù declared là text hợp lệ).
3. **DNS-rebinding defense:** hostname phân giải tới `10.0.0.5` →
   `ARTIFACT_URL_BLOCKED` dù URL literal trông công khai.
4. **Redirect pinning:** hop tới `169.254.169.254` bị chặn giữa chuỗi; vòng
   lặp A↔B → `URL_FETCH_REDIRECT_LOOP`.
5. **Paywall/login:** 402/403 → `URL_ACCESS_RESTRICTED`, và test xác minh
   `credentials: "omit"` (không gửi kèm phiên đăng nhập).
6. **Body/type caps:** body quá lớn → `URL_FETCH_TOO_LARGE`; content-type
   executable → `URL_CONTENT_TYPE_BLOCKED`; chuỗi redirect an toàn trả đủ
   `redirectChain` + content.
7. **Fetcher wiring:** URL artifact qua fetcher thành text-ready với
   `sourceText`; URL paywall → `blocked`/`URL_ACCESS_RESTRICTED`.

## 4. Quyết định triển khai (trong phạm vi R1.8, không tạo `D-*` mới)

1. **Scanner thuần deterministic local** (chuẩn EICAR + magic bytes) thay vì
   chờ malware-scanner service — fail-closed ngay được, port để nối scanner
   thật; `needs_review` giữ chỗ cho escalation.
2. **Fetcher là port tùy chọn**, mặc định TẮT để hành vi VS1 không đổi (không
   có network call ngầm); bật = truyền `urlFetcher` khi cấu hình service.
3. **Fallback metadata-only cho lỗi transport** (DNS/timeout/5xx) thay vì block
   — link artifact vẫn là bằng chứng nguồn; riêng blocked/restricted fail-closed.
4. Reason code dùng chung vocabulary `SAFETY_*`/`URL_*` machine-safe
   (`[A-Z][A-Z0-9_]{0,127}`) khớp luật error code P03.

## 5. CÒN MỞ sau R1.8

1. **Ghim IP cho TCP connection** (custom lookup/agent) + egress policy thật
   trên Cloud Run — mục staging.
2. **Malware-scanner thật** (ClamAV/API) qua `ContentSafetyScanner` port +
   `needs_review` workflow (moderation cases).
3. **Transcript Facebook/YouTube** theo điều khoản nền tảng (hiện metadata
   only; không vượt login/paywall).
4. **Giải nén archive bị chối** — hiện chặn cả archive; nhu cầu nhận
   zip học liệu cần rule giải nén an toàn + quota.
5. **DAST/pentest staging** với ZAP/Burp — cần staging build (P05-R2).
